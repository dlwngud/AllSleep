# AllSleep 작업 지침 적용 상태

기준일 2026년 10월 13일

프로젝트 루트 AGENTS.md가 작성되어 현재 작업 기준으로 사용된다. 기존의 마지막 단계에서 지침을 새로 작성한다는 제안은 로드맵 v2에서 대체되었다.

현재 지침은 UX, 단순한 구조, 빠른 사용자 가설 검증, 실제 검증 결과와 데이터 보존을 중심으로 한다. 테스트 커버리지 100%나 모든 작업의 긴 설계 문서·별도 승인·새 작업 공간을 목표로 두지 않는다.

각 구현 단계에서 구조·기술·명령·제품 규칙의 실제 변경이 생기면 AGENTS.md와 해당 자료를 함께 갱신한다. 적용 중인 기준은 [루트 AGENTS.md](../../AGENTS.md), 실행 순서는 [로드맵 v2](IMPLEMENTATION-ROADMAP.md), 완료 상태는 [진행표 v2](IMPLEMENTATION-STATUS.md)에서 확인한다.

2026년 10월 12일의 구성 제안과 지침 초안은 [이전 제안 기록](planning-history/2026-10-12-v1/AGENT-GUIDE-PROPOSAL.md)에 보존한다. 이 기록은 현재 지침이 아니다.
