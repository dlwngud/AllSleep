# AllSleep 최종 취침 약속 제품 설계

2026년 10월 13일 갱신. 최종 제품 제안은 정상 화면과 조건별 상태를 합쳐 93개입니다. 네이티브 앱 기능은 이번 시안 작업에서 새로 구현하지 않았습니다.

## 살펴보는 순서

1. `final-screen-gallery.html`: 모든 화면을 영역별·검색으로 확인하고 클릭해 크게 봅니다. 이미지가 내장되어 인터넷 없이 열립니다.
2. `allsleep-prototype.html`: 실제 화면 버튼으로 온보딩, 밤, 아침, 계정·Plus 흐름을 살펴봅니다. 긴 본문은 세로로 스크롤합니다.
3. `FINAL-SCREEN-CATALOG.md`: 93개 목록과 추가 26개 화면의 기존 21단계 구현 매핑을 확인합니다.
4. `PRODUCT-VALUE-AND-COMPETITION.md` 또는 `value-and-competition.html`: 사용자 가치, 공식 자료 기반 경쟁 비교, 유료 이유와 검증 가설을 읽습니다.
5. `PRODUCT-PLAN.md`, `SCREEN-SPEC.md`, `IMPLEMENTATION-ROADMAP.md`: 제품 요구, 화면별 예외·완료 조건과 단계별 구현 범위를 확인합니다.
6. `../../output/pdf/allsleep-final-screen-book.pdf`: 전체 시안 50페이지. `allsleep-value-and-competition.pdf`: 가치와 경쟁 전략 5페이지.

`boards/01.png`부터 `10.png`까지 영역별 전체 화면 보드를 제공합니다. 2026-10-12의 36페이지 디자인북과 기획서 PDF는 이전 산출물이며 최신 화면은 50페이지 시안집을 사용합니다.

## 제안 범위

- 무료: 한 기기 제한, 평일·주말 기본 루틴, 오늘만 변경, 임시·긴급 접근, 원본 기록과 기본 요약. 백업을 원할 때 로그인합니다.
- 최종 Plus: 지원 Android 기기 최대 5대, 복수 루틴, 장기 비교, 7일 조정 계획. 최초 유료 검증에서는 실제 완성된 기기 연동만 판매합니다.
- 월 4,900원·연 39,000원·연간의 자격별 7일 체험은 상품 가설입니다. 실제 구매는 스토어 조회 조건을 사용합니다.
- Android 우선. iOS는 별도 승인·권한·실기기 검증 후 범위를 확정합니다. PC·TV 제한은 판매 범위가 아닙니다.
- 사용 제한이 실제 수면 시간이나 수면의 질을 뜻하지 않습니다.

## 시안의 동작

모든 날짜·계정·기기·기록·가격은 합성 예시입니다. 실제 인증·결제·제한·문의·파일 생성·삭제를 실행하지 않습니다. 입력값은 서버로 보내거나 영구 저장하지 않습니다. 스토어·권한·공유 화면은 실제 Android 시스템 UI를 사용해야 하며 시안은 진입과 결과 맥락을 보여 줍니다.

로그인이나 연결 상태를 검토하기 위해 버튼으로 다음 상태를 보여 주는 곳이 있습니다. 실제 앱에서는 검증된 완료 응답 없이 다음 상태로 이동하면 안 됩니다. 93개 시안은 93개의 독립적인 navigation destination을 요구하지 않습니다. 공통 로딩·저장 중·간단한 오류는 같은 화면의 상태로 구현합니다.

## 검수 결과

93개 화면을 390px과 360px에서 렌더링하여 가로 잘림·이미지 누락·주 버튼 높이를 확인했습니다. 전체 갤러리의 검색·확대·모바일 표시를 확인했습니다. 오프라인 단일 HTML에서 게스트 마이, 주말 변경의 평일 보존, 유료 의도 뒤 로그인 복귀, 체험 비대상 청구, 구매 검증 대기, 기기 승인 대기, 삭제 접수·완료와 내보내기 준비 상태를 포함한 11가지 흐름 점검을 통과했습니다.

PDF 총 55페이지를 이미지로 렌더링하여 검수했습니다. 실제 Android의 TalkBack·큰 글꼴·키보드·서비스·정확한 일정·결제 및 OS 동작은 구현 단계의 별도 검증 대상입니다. 시안 검수 결과로 네이티브 기능 완료를 주장하지 않습니다.

재생성 도구는 `qa/build-final-design.cjs`이고 흐름 점검은 `qa/test-final-flows.cjs`입니다. Codex 번들 런타임·Playwright·Chrome 경로는 현재 작업 환경에 맞춰져 있습니다. `qa/build-and-verify.cjs`는 최신 생성 도구의 별칭입니다.
