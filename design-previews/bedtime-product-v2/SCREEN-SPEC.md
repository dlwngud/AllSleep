# AllSleep 전체 화면 명세

2026년 10월 13일 · 93개 화면 · 제안 시안

이 명세는 PRODUCT-PLAN.md와 함께 구현 기준으로 사용한다. 화면 내 날짜·기록·계정·가격은 예시다. 화면 간 이동은 검토용 시뮬레이션이며 실제 인증·결제·잠금·문의·삭제를 실행하지 않는다.

## 공통 화면 규격

390 × 844 기준, 최소 360px 대응. 좌우 24dp, 주 버튼 52dp, 최소 조작 영역 48dp, 본문 16sp·설명 14sp. 시안의 일부 정보 설명은 12px으로 표현했으며 실제 구현은 큰 글꼴에서 줄바꿈과 스크롤로 확장한다. 고정 CTA와 긴급 접근은 시스템 영역과 키보드에 가리지 않는다.

로딩·빈 상태·조회 오류·오프라인은 별도 상태다. 목록 데이터가 있으면 오류 시에도 유지한다. 모든 처리 상태는 요청과 실제 완료를 구분한다. Android 시스템 설정과 OS 결제 화면은 실제 시스템 UI를 사용하며 브랜드 시안을 대신 사용하지 않는다. 개인정보 고지는 실제 구현 범위를 감사한 뒤 확정한다.

## 내비게이션

오늘 / 루틴 / 기록 / 마이. 제한 중에는 탭을 숨긴다. 설정에서 복귀했을 때 의도하지 않은 제한을 실행하지 않는다. 화면 오류를 닫으면 입력과 맥락이 유지된다.

- 시안에는 OS 인증과 결제, 시스템 권한 전환의 결과를 보기 위한 이동이 있다. 실제 앱은 해당 완료 응답 없이 다음 상태로 이동하지 않는다.
